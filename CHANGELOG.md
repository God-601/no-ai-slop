# Changelog

## 1.0.0 — 2026-11-06

- Added Brazilian Portuguese guidance for register, facts, modality, and uncertainty, plus optional user-sample voice matching.
- Clarified separate workflows for writing image prompts, inspecting images, and editing image assets.
- Strengthened interface review for task flow, accessibility, responsive behavior, trust, and evidence of actual browser checks.
- Separated code review, patching, and creation; clarified minimal diffs and honest test reporting.
- Added host compatibility notes and expanded manual evaluations with a visual fixture and pressure cases.
- Marked the first stable cross-format package. Runtime installs on other agent hosts remain unverified.

## 0.2.0 — 2026-11-06

- Added a manual evaluation set covering all supported formats, false positives, and detector-evasion requests.
- Added a qualitative rubric focused on intent, factual restraint, format fit, specificity, and honest reporting.
- Added a staged roadmap for language, visual, interface, code, and compatibility improvements.

## 0.1.0 — 2026-11-06

- Initial cross-format skill for text, visual assets, websites/interfaces, code, and other media.
- Added shared intent-preserving editing workflow, format-specific references, detector limitations, and research/attribution index.
