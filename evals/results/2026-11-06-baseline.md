# Baseline observations — 2026-11-06

Before the 1.0.0 changes, two fresh subagents without access to the repository
answered the eight initial cases and six pressure cases. Across those two
baseline runs, the responses met the visible expected behaviors on all 14
prompts at a basic qualitative level.

This is a useful control, but it does **not** show that the skill caused the
behavior or improves results. The default agent already handled the cases
without it, and one run cannot establish consistency or cross-agent support.
The suite therefore checks guardrails and task-fit rather than claiming a
measured gain. Future evaluations should use repeated runs and real user cases
before making comparative claims.
