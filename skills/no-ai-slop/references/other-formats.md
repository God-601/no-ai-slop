# Other-format review mode

Use this mode for audio, video, presentations, documents, data visualizations, 3D assets, and formats without a dedicated reference.

1. Identify what the artifact is for, who will use it, and what constraints matter.
2. Preserve the user's intended message, aesthetic direction, and factual content.
3. Inspect the format's core quality dimensions: coherence, usefulness, craft, accessibility, technical fit, and consistency with the brief.
4. Separate concrete defects from personal taste. Do not treat any single style feature as evidence of AI authorship.
5. Make targeted corrections with the available tools. If direct editing or inspection is unavailable, return precise instructions and state the limitation.
6. Explain the changes and anything left unverified.

For an unfamiliar format, ask one or more focused questions only if the answers would materially change what a good result looks like.
